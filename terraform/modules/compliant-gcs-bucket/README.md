# This terraform evidence based on the Google Cloud Platform shows the real time work that goes into the implementation of six controls. First, the SC-12 control is in place because of the crypotgraphic key that is established and owned not by a third party, but me. Second, SC-13 and SC-28 controls demonstrate cryptography at rest and the interval for rotation in the dev environment. AU-11 spells out what the retention policy is regarding the key which is set to false for demonstration purposes, however, if it were set to true - that would be in place for exactly the specified timeframe. CM-6 puts a label on the key and includes the environment, scope, and project the key sits in on GCP. Finally, I like to think of AC-3 as a prefix for "ACcess" because it is a key in place that prevents the public from accessing it and compromising security.
